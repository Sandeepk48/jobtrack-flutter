# 💼 JobTrack

> A production-style Flutter Job Application Tracker built in public.

**JobTrack** is a real-world mobile application designed to help job seekers organize, track, and manage their entire job-search journey from one place.

This project is being built as a **45-day Build in Public journey**, applying practical Flutter development experience to a complete production-style application.

---

## 🚀 Project Goals

JobTrack aims to provide a simple but powerful way to:

- 📋 Track job applications
- 📌 Manage application stages
- 🔎 Search, filter, and sort opportunities
- 📅 Track interviews and follow-ups
- 📝 Store interview notes
- 📎 Manage job-related documents
- 📊 Understand application progress through analytics
- 🔔 Receive useful reminders
- 📴 Continue working when offline
- ☁️ Synchronize data when online
